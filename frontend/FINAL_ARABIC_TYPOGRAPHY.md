# DOCTECH — amélioration arabe / RTL

Cette version comprend :

- police globale sans-serif pour éviter l'arabe serif par défaut du navigateur ;
- pile arabe Windows/Web : Segoe UI, Tahoma, Arial, Noto Sans Arabic ;
- suppression automatique du letter-spacing Tailwind en arabe ;
- lignes plus aérées pour les titres et paragraphes arabes ;
- remontée légère des labels 7–12 px uniquement en arabe ;
- RTL mémorisé dans localStorage et appliqué très tôt avant hydratation ;
- Header final avec menus déroulants Catégories / Marques ;
- sélecteur de langue en haut avec drapeaux 🇫🇷 / 🇩🇿 ;
- mêmes corrections côté client et administration.

Aucun fichier de police externe n'est nécessaire.
